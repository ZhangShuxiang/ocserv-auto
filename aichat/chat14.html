联网搜索

在输入框开启「联网搜索」后，模型可自主决定何时调用 web_search 工具。 默认使用 Tavily：填好 API Key 即可，Key 可在 app.tavily.com 免费申请（每月有免费额度）。输入框旁的下拉框可切换本次使用的搜索接口，也可在下方增删改。 浏览器直连搜索服务需要目标接口允许 CORS（Tavily 已支持；自建 SearXNG 需自行开启 CORS）。

知识库

支持 .txt / .md / .json。JSON 可以是 [{title, content}]、["文本"] 或 {documents:[...]}。导入后立即生效，在输入框「知识库」中选择使用。
